## Implementation and repairs

- Migrated the baseline into typed Svelte components, a Rust timing kernel and native CPAL synthesis. Rendering responds to snapshots at approximately one-second boundaries; CSS controls local flip/hand animation.
- Native timer uses a continuous clock including sleep; saved wall deadlines recover after restart. Added coverage for pause/resume, wall-clock changes, expiry once, daily alarm, snooze and invalid input.
- Built a fixed-voice audio callback with a bounded lock-free queue. Found and repaired an onset bug: a delayed output callback could skip the entire short tick. The regression test preserves a late event's attack.
- Separated desktop host compilation from pure unit tests after tracing `STATUS_ENTRYPOINT_NOT_FOUND` to GUI activation-context requirements in the test executable.
- Cargo originally selected Tauri 2.11 because the project's declared MSRV was 1.88. The npm API was 2.12, and the official CLI correctly rejected the mismatch. Raised MSRV to 1.90 and aligned the Rust dependency to 2.12.4 rather than disabling the compatibility check.
- Direct Cargo release builds require `--features tauri/custom-protocol` for embedded frontend resources. Official Tauri CLI builds manage this feature. Checked the production origin is `http://tauri.localhost/` instead of the development server.
- Formatted maintained source and pinned lockfiles. The original Electron implementation remains an unchanged baseline.
