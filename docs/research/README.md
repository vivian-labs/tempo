# Research index

Research inputs are public release artifacts and primary documentation. Each finding must state what was observed and what remains an inference.

- `flitik-implementation.md`: REA build facts, static dependency and asset evidence, interaction observations and limits.
- `design-system.md`: materials, typography, motion, audio and urgency distilled into TEMPO's own design.
- `evidence-summary.json`: small reproducible artifact identities and tool result summaries, excluding proprietary payloads.

Raw release packages, extracted code/media, local analysis engines and full REA evidence remain in `.local/research` and are excluded from Git.
