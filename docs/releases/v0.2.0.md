# 一刻 · TEMPO 0.2 · 时间，有形

公开预览版，支持 Windows x64、Mac Apple Silicon 和 Mac Intel。

- 实体机械盘、可拖动指针与逐渐消失的倒计时扇区。
- 上下分片的翻页时钟，逐秒跳动和匀速指针选项。
- 每日闹钟、5 分钟后提醒、到时提示和最后一分钟的紧迫氛围。
- 三种原创程序化机械音色，独立滴答开关与总音量。
- 全屏、窗口置顶、静止隐藏操作界面，三种主题及可关闭数字读数。
- Tauri 2.12.4 + Svelte 5 + TypeScript + Rust；原生计时和音频与显示分离。

验证：5 项前端单测、13 项原生测试；Windows CI 安装器中的程序已在本机通过 7 项交互场景和 8 张布局截图检查。Mac 两种架构均通过原生构建、测试、DMG 打包和应用启动检查。

包体约 1.8 MB（Windows 安装器）、2.4 MB（Apple Silicon DMG）、2.5 MB（Intel DMG），使用系统 WebView。完整进程树短测和内存口径见 [性能报告](../benchmarks/2026-10-16.md)。研究与设计依据见 [FliTik / REA 研究](../research/flitik-implementation.md)。

安装包暂未签名或公证。Mac 真机音效、休眠恢复和 Retina 视觉验收仍待完成。闹钟需保持应用运行，电脑休眠时不会响铃。随发布提供 SHA-256 校验值。
